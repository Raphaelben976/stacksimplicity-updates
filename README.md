# StackSimplicity RMM — update repository

Signed agent releases for StackSimplicity RMM, served at `https://updates.stacksimplicity.com/`.

This is a [TUF](https://theupdateframework.io/) repository: every file is signed offline by the publisher, and every instance and agent verifies the whole chain from its built-in root before using anything. Hosting it here adds no trust: a modified file is refused.

Do not open pull requests here. To report a security issue, write to security@stacksimplicity.com.
